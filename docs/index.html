    Install

    Skills are plain folders in the open Agent Skills format. Pick the route that fits your agent.

    Claude Code plugin

    All skills, kept up to date.

    /plugin marketplace add M2LabOrg/agent-skills
/plugin install m2lab-skills@m2lab

    Any agent: skills CLI

    Pick skills and target agents interactively.

    npx skills add M2LabOrg/agent-skills \
  --skill debugging-discipline

    Any agent: from a clone

    Copy or symlink into any skills folder.

    git clone https://github.com/M2LabOrg/agent-skills.git
agent-skills/scripts/install.sh --agent copilot
# claude | copilot | agents | opencode
# or --target <any/skills/dir>

    Folders: .claude/skills/ (Claude Code), .github/skills/ (GitHub Copilot), .agents/skills/ (Codex and other tools sharing it), .opencode/skills/ (OpenCode). See the Agent Skills format.

    Authoring conventions

    What makes a skill in this collection.

    Descriptions that trigger precisely

    The description is the trigger: what the skill does, Use when …, and Do not use …, under 1024 characters.

    Progressive disclosure

    Keep SKILL.md under ~500 lines. Push detail into references/ so the model only reads it when needed.

    One skill = one folder

    SKILL.md plus scripts/ to run, references/ to read on demand, assets/ to copy, and evals/ to test triggering.

    Self-contained and tool-agnostic

    Relative paths only, no tool-specific variables, no dependencies on other repositories. Each skill captures how to work, so it applies to any codebase.
